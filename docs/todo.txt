B. Design decisions

C. Assumptions and limitations

Documents things that aren't necessarily enforced by the code.

For example:
- Input ordering is assumed to be temporal.
- Sequence construction assumes observations are already appropriately ordered.
- Normal-only training is an assumption of certain model families, not every anomaly detector.
- Window labels depend on the selected labeling policy.
- Threshold selection is separate from model training.
This third category is particularly valuable. It prevents someone from misunderstanding what the system guarantees versus what it assumes
